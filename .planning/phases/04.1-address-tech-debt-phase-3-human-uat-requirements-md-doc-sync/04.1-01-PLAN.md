<objective>
Land the two code-level tech-debt items from `.planning/v1.0-MILESTONE-AUDIT.md` §5: **WR-07** (difftool full-file rendering reads the wrong side of the diff for deleted files, with no regression test guarding it) and **IN-01** (`gofmt` drift that CI cannot see because `.golangci.yml` has no `formatters` block).

Purpose: WR-07 is a real violation of `AlignFull`'s documented contract (`internal/diff/align.go:254-261`) that is currently masked by a coincidence — whole-file deletions always parse as exactly one hunk, so the inter-hunk gap-filling that needs the old-file content never runs. That coincidence is not a design guarantee, and nothing in the test suite would catch it changing. IN-01 makes the formatting invariant machine-enforced rather than reviewer-enforced.

Output: a fixed and renamed `DifftoolInfo` reference-content field, a new regression test with a sensitivity control, a gofmt-clean module, a `formatters` block in `.golangci.yml`, and a CI lint job that actually passes.
