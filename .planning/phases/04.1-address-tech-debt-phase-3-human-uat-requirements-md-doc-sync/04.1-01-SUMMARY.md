## Accomplishments
- Closed WR-07: `loadDifftoolFiles` (`cmd/alturd/main.go`) now branches on `files[0].IsDelete` to read the reference-version content for full-file rendering from `--difftool-local` instead of unconditionally from `--difftool-remote`, honouring `AlignFull`'s documented old-file-for-deletions contract. Previously a deletion's `$REMOTE` is git's `/dev/null`, so opening a deleted file in `git difftool -t alturd` and toggling to full-file mode (`v`) silently rendered nothing.
- Added `TestLoadDifftoolFilesDeletedFileUsesLocalSide` (`cmd/alturd/loaddifftoolfiles_internal_test.go`) with a `deleted_file_uses_local` subtest (proves the fix end-to-end through `diff.RenderFull`) and a `modified_file_uses_remote` sensitivity control (fails if the branch is inverted, not just removed). Fault injection was run and reverted before committing: removing the branch fails the first subtest; inverting it fails both.
- Renamed `DifftoolInfo.NewFileLines` → `RefFileLines` (three call sites) since the field no longer always holds post-image content.
- Closed IN-01: `gofmt -w` swept 5 drifted files (the 3 named by the milestone audit plus 2 more that drifted after that review, including this plan's own new test file) and added a top-level `formatters:` block to `.golangci.yml` enabling `gofmt`/`goimports`, sibling to the untouched `linters:` block.
- Cleared 7 pre-existing `golangci-lint` findings (5 `errcheck`, 2 `revive`) discovered during planning — not in `04.1-CONTEXT.md` but required so the new `formatters` gate lands on an already-green CI lint job rather than being unreadable noise on a red one.

### Environment Limitation (not a deviation, not a code defect)

**1. `go test -race ./...` cannot run in this execution sandbox**
- **Found during:** Task 1 verification, re-confirmed at overall plan verification
- **Issue:** The plan's `<verify>` blocks and overall `<verification>` require `go test -race ./...`. This sandbox has `CGO_ENABLED=0` and no `gcc`/`cc` on `PATH`, and no root/sudo to install a C toolchain. `-race` requires cgo, so the command fails immediately with `go: -race requires cgo; enable cgo by setting CGO_ENABLED=1` before any test runs.
- **Mitigation:** `go test ./...` (without `-race`) was run instead at every verification point and is fully green across all packages, including the new WR-07 test and the punctuation-updated `installdifftool_test.go`.
- **Recorded:** `.planning/WINDOWS.md` entry (id 2, kind `unrun-verify`, phase `04.1`) — flags that `-race` must be re-run in an environment with a working C toolchain before this can be considered fully verified per the plan's own bar.
- **Files affected:** none (verification-only, no source change)
