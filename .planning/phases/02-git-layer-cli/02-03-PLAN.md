    Add the two deps pinned to RESEARCH.md versions: `go get github.com/spf13/cobra@v1.10.2` and `go get golang.org/x/term@v0.44.0`, then `go mod tidy`. Both must be CGO-free.

    Create `cmd/alturd/main.go` in `package main`. Declare `var version = "dev"` (a package-level var, NOT a const — goreleaser overrides it via -ldflags in Phase 4, per D-03).

    Define `rootCmd` as a `*cobra.Command` with: `Use: "alturd [ref] [ref1..ref2] [-- paths]"`, `Short: "Side-by-side terminal diff viewer"`, `Version: version`, `SilenceErrors: true`, `SilenceUsage: true`, `Args: cobra.ArbitraryArgs`, `RunE: run`. SilenceErrors/SilenceUsage are required so main() fully controls error output (no cobra "Error:" prefix as a second line). No subcommands are registered (per D-02 — install-difftool arrives in Phase 4).

    Implement `func run(cmd *cobra.Command, args []string) error`:
    1. FIRST statement: `logFile, err := applog.Init()`. On success `defer logFile.Close()`; on error treat as non-fatal (continue without logging). This MUST be the first statement so --version/--help (which exit inside cobra before RunE) never create a log file (per D-10, Pitfall 1). Do NOT place Init in init() or PersistentPreRunE.
    2. Build git args: `gitArgs := append([]string{"diff"}, git.ParseRefArgs(args, cmd.ArgsLenAtDash())...)`. The literal "diff" is prepended here (Runner does not add it).
    3. Run: `reader, err := git.ExecRunner{}.Run(gitArgs)`; if err != nil return it unchanged (it is already an *ExitCodeError for the no-repo/no-git cases, or a wrapped error otherwise).
    4. Parse: `files, err := diff.Parse(reader)`; wrap errors with %w.
    5. Compute width via a `terminalWidth()` helper (Pattern 6): if `term.IsTerminal(int(os.Stdout.Fd()))` and `term.GetSize` returns w>0, use w; else fall back to 160 (per D-07).
    6. Render: iterate `files`, and for each file call `diff.Render(file, width)` (single-file signature) and write every returned row to stdout followed by a newline. Use a buffered writer or fmt.Fprintln(os.Stdout, row).
    7. return nil.

    Implement `func main()`: call `rootCmd.Execute()`; on non-nil error, `errors.As(err, &exitErr)` for `*git.ExitCodeError` → `fmt.Fprintln(os.Stderr, exitErr.Msg)` then `os.Exit(exitErr.Code)`; otherwise `fmt.Fprintln(os.Stderr, err.Error())` then `os.Exit(1)`. All error output is a single line to stderr (per D-11). Follow the import-group ordering (stdlib / third-party / project-internal) from PATTERNS.md.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI flags/args → RunE | User-supplied flags and ref/path args cross into the command handler |
| RunE error → main()/os.Exit | Error type determines process exit code and stderr output |
| git subprocess stdout → stdout render | Untrusted subprocess output rendered to the user's terminal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Information Disclosure | main() error output | medium | mitigate | All failures print a single fixed line to stderr (ExitCodeError.Msg or err.Error()); SilenceErrors/SilenceUsage suppress cobra's verbose usage/error dump; raw git stderr is not echoed |
| T-02-08 | Tampering | RunE log-init ordering | medium | mitigate | applog.Init is the first RunE statement, never init()/PersistentPreRunE, so --version/--help create no file — verified by the no-log integration tests (GIT-04, D-10) |
| T-02-09 | Repudiation | exit-code routing | low | mitigate | Distinct, tested exit codes (0 success, 1 no-repo, 127 git-not-found) via errors.As(*git.ExitCodeError) give callers/CI deterministic, scriptable signals |
| T-02-01 | Tampering | git invocation via ExecRunner | high | mitigate | Inherited from Plan 01: argv-form exec.Command, no shell; main only prepends the constant "diff" token (ASVS V5) |
| T-02-SC | Tampering | cobra + x/term dependencies | low | accept | Pinned to audited versions (cobra v1.10.2, x/term v0.44.0); RESEARCH.md Package Legitimacy Audit verdicts OK via proxy.golang.org; x/term is an official Go extended lib, cobra is locked by D-01 |
