<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 3: Human visual smoke check of the running TUI</name>
  <action>Pause for a human to run the built binary in a real terminal and confirm the interactive TUI renders and navigates correctly per the steps below. This checkpoint cannot be automated (real TTY required, VALIDATION.md manual-only list).</action>
  <what-built>
    An interactive split-screen TUI: `alturd` launched in a git repo shows the file tree (left) and the side-by-side diff (right) with a status bar, and responds to the full keybinding set (Tab focus, ]/[ file cycle, n/N hunk nav, v mode toggle, / search, a full-repo toggle, q/Q quit). Automated tests cover the dispatch logic; terminal visual quality requires a real TTY (VALIDATION.md manual-only list).
  </what-built>
  <how-to-verify>
    1. In a git repo with 3+ changed files, run: `go run ./cmd/alturd` (or build with `go build -o /tmp/alturd ./cmd/alturd && /tmp/alturd`).
    2. Confirm the split screen: file tree on the left (~24 cols) with [A]/[M]/[D]/[R] markers and a │ separator, diff on the right, and a top status bar `alturd — <file> (N of M changed files)`.
    3. Press Tab — the tree should instantly widen to ~45 cols and the selected row should show inverted highlight; press Tab again to contract to ~24.
    4. Press ] and [ — the displayed file and the status-bar "N of M" should change with wraparound.
    5. Press n / N — the diff should jump between hunks with the changed line roughly centered.
    6. Press v — the view should toggle between full-file and hunk-only without a visible reload.
    7. Press / — a search bar should appear at the bottom of the diff pane; type a substring present in the diff and confirm matches highlight; press n/N to move between matches; press Esc to close and clear highlights.
    8. Press a — the tree should switch to the full-repo listing (changed files keep their markers); press a again to return to changed-only.
    9. Press q — the app should exit cleanly with code 0 (run `echo $?`).
    10. Separately run `alturd --version` and `alturd --help` and confirm they exit 0 with no TUI and no log file created.
  </how-to-verify>
  <resume-signal>Type "approved" or describe any layout, color, navigation, or search issues observed.</resume-signal>
