<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user search query → matcher/highlighter | Untrusted typed text; used only as a strings.Index needle and never re-emitted as escape sequences |
| git ls-tree subprocess → tree | Repo-controlled path strings enter as display labels and tree keys |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05 | Tampering | Shell injection via git ls-tree invocation | medium | mitigate | Command runs through git.ExecRunner{}.Run with an argv slice (exec.Command form, not a shell string) — reuses the Phase 2 chokepoint; no user input is concatenated into the argument list |
| T-03-PATH | Spoofing | Path traversal via git ls-tree output | low | mitigate | ls-tree paths are split on newline and used only as tree display strings and map keys; Phase 3 performs no os.Open/Stat/filepath resolution on them (V5, display-only) |
| T-03-SEARCH | Tampering | ANSI/terminal-escape injection via search query | low | mitigate | Query is matched against ansi.Strip'd content and passed to viewport.SetHighlights as plain-text integer positions; it is never interpolated into ANSI output |
</threat_model>
