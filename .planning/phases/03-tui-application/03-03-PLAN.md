<objective>
Build the core bubbletea v2 state machine in internal/tui/model.go: the model struct, constructor, Init (with Windows resize polling), View (split layout + status bar + tree rendering), resize handling, diff/tree content refresh, and the full normal-mode key dispatch (Tab, ]/[, v, n/N hunk nav, q/Q). This makes alturd a navigable split-screen TUI for everything except search and the full-repo toggle (Plan 04).

Purpose: This is the interaction backbone. It consumes diff.Render(file, w, mode) and diff.HunkStartRows (Plan 01) plus buildTree/flattenTree (Plan 02) and turns pre-loaded diff data into a keyboard-driven two-pane view.
Output: model.go implementing tea.Model with normal-mode navigation; model_test.go proving the dispatch behavior; the three charm.land v2 dependencies installed.
</objective>
