<objective>
Build the parsing and alignment stages of the diff pipeline. `parse.go` wraps go-gitdiff into a no-panic `Parse` function; `align.go` transforms a parsed file into `[]RowPair` (the side-by-side row model), pairing adjacent delete+add lines as Modified, emitting blank fillers for one-sided changes, honoring FullFile vs HunkOnly mode (DIFF-05), and producing correct placeholders for binary, mode-only, and submodule files (DIFF-07). Both stages are validated by table tests against the full fixture corpus using structural assertions only (D-05).

Purpose: This is the data-transformation core of the library — it converts raw git diff text into the aligned row structure that highlighting and rendering consume. Correctness here gates everything in Plan 03.
Output: `parse.go`, `align.go`, and their table tests, all green against the 13-fixture corpus.
</objective>
