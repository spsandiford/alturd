<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RowPair content → DiffMain | Arbitrary line content fed to character-level diff |
| RowPair content → Chroma | Arbitrary content fed to the tokenizer |
| binary fragment → Render | Non-text bytes must not enter the text render path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Denial of Service | `DiffMain` on extremely long/complex lines | high | mitigate | 1000-char + 200-token pre-guards (`shouldSkipIntraLine`) plus a 100ms goroutine timeout (`computeIntraLineWithTimeout`) bound CPU/memory; verified by large-line.diff and many-tokens.diff tests (D-07; ASVS V5) |
| T-01-07 | Tampering | binary bytes rendered as text | medium | mitigate | Binary files early-return the Align placeholder; never split on newline or tokenised (RESEARCH Pitfall 6) |
| T-01-08 | Information Disclosure | chroma color bleed across columns | low | mitigate | Explicit `ansiReset` at left-column boundary and per-line reset after split prevent state leak (RESEARCH Pitfall 1/2) |
</threat_model>
