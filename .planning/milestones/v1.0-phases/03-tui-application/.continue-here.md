<decisions_made>

- `AlignFull(file, fileLines)` takes a single `[]string` (reference file content — new file for modified/added, old file for deleted) rather than both old and new, keeping the API simple while correctly handling all cases
- `HunkStartRowsFull` needs no file content — computes hunk positions from `frag.OldPosition`/`frag.NewPosition` and `frag.OldLines`/`frag.NewLines`
- `fetchFileLines` priority: `git show HEAD:path` → `git show :path` → `os.ReadFile` (git paths are repo-root-relative so they work from any CWD)
- `scrollToFirstHunk()` is NOT called from `handleResize` to avoid snapping position on terminal resize
- FullFile fallback (when fetchFileLines fails) uses `diff.Render(file, diffW, diff.FullFile)` — shows hunk context rather than degrading to HunkOnly
</decisions_made>
