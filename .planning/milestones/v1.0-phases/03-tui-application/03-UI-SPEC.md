## Layout — Terminal Cell Geometry

Spacing in terminal UIs is measured in columns (horizontal) and rows (vertical), not pixels. The 8-point grid concept maps to whole-cell increments.

### Pane Widths

| Pane | Unfocused Width | Focused Width | Notes | Source |
|------|----------------|---------------|-------|--------|
| File tree pane | 24 columns | 45 columns | Instant resize on `Tab` — no animation state machine | CONTEXT.md D-02 |
| Separator | 1 column | 1 column | Unicode `│` (U+2502), always present | CONTEXT.md D-01 |
| Diff pane | `termWidth - treeWidth - 1` | `termWidth - treeWidth - 1` | No minimum; fills remaining width | CONTEXT.md D-03 |

Filename truncation: `lipgloss.Style.MaxWidth(treeWidth - 4).Render(name)` — ellipsis appended at end when truncated. Applied at 24-col unfocused width. (CONTEXT.md D-04)

### Row Heights

| Element | Height | Condition | Source |
|---------|--------|-----------|--------|
| Status bar | 1 row (always, top of screen) | Always | CONTEXT.md D-05 |
| Content area (tree + diff viewports) | `termHeight - 1` rows | Search closed | CONTEXT.md D-05, D-13 |
| Content area | `termHeight - 2` rows | Search open | CONTEXT.md D-13 |
| Search bar | 1 row (bottom of diff pane) | When `searchMode = true` | CONTEXT.md D-13 |

### Viewport Sizing Formulas

Authoritative formulas for `handleResize()` and search-mode toggle — apply on every `tea.WindowSizeMsg`, every `Tab` keypress, and every `searchMode` toggle:

```
contentH = termHeight - 1             // always subtract status bar
if searchMode { contentH -= 1 }       // subtract search bar when open

treeWidth = 24  (when unfocused)  |  45  (when focused)
diffWidth  = termWidth - treeWidth - 1

treeVP.SetWidth(treeWidth)
treeVP.SetHeight(contentH)
diffVP.SetWidth(diffWidth)
diffVP.SetHeight(contentH)
```

### Startup Guard

`View()` returns `tea.NewView("")` until the first `tea.WindowSizeMsg` sets `ready = true`. This prevents blank/zero-width viewport rendering on the first frame. (CONTEXT.md D-07)

## Typography

All terminal text is monospace. Size is set by the terminal emulator — not configurable in-app. ANSI codes control weight and highlight only.

| Role | Rendering | ANSI Code | Usage |
|------|-----------|-----------|-------|
| Body text | Regular weight | (none — terminal default) | Tree entries, context diff lines, status bar, search prompt |
| Intra-line emphasis | Bold | `\x1b[1m` … `\x1b[22m` | Character-level changed spans on modified lines (DIFF-04) |
| Selected row | Reverse video | `\x1b[7m` (via `lipgloss.NewStyle().Reverse(true)`) | Currently selected tree row (D-12) |
| Search match | Reverse video | `\x1b[7m` (via `viewport` `HighlightStyle`) | Match positions in diff pane (SEARCH-01) |

Line height: always 1 terminal row. No wrapping in the diff pane — `truncateANSI()` clips long lines to `colWidth`.

## Color — ANSI 256-Color

All colors are 256-color ANSI sequences. Hardcoded in Phase 3; Phase 4 will introduce theme-configurable values via TOML config.

### Diff Line Background Colors (existing — from `render.go`)

| Role | ANSI Sequence | Color Index | Appearance | Line Kind |
|------|---------------|-------------|------------|-----------|
| Added line | `\x1b[48;5;22m` | 22 | Dark green | `LineAdded` |
| Removed line | `\x1b[48;5;52m` | 52 | Dark red | `LineRemoved` |
| Modified line | `\x1b[48;5;58m` | 58 | Dark amber/olive | `LineModifiedOld`, `LineModifiedNew` |
| Context line | (none) | — | Terminal default | `LineContext`, `LineBlank` |
| Column boundary reset | `\x1b[0m` | — | Terminal default | Applied at every left-column boundary |

No changes to these constants in Phase 3 — they already exist in `render.go` as `bgAdded`, `bgRemoved`, `bgModified`.

### TUI Chrome Colors (Phase 3 additions)

| Role | Implementation | Usage | Source |
|------|----------------|-------|--------|
| Selected tree row | `lipgloss.NewStyle().Reverse(true).Render(row)` | Highlights the currently selected file in the tree (D-12) | CONTEXT.md D-12 |
| Search match highlight | `viewport.HighlightStyle = lipgloss.NewStyle().Reverse(true)` | Match positions in diff viewport — reverse video visible on any background | RESEARCH.md Open Question 2 |
| Pane separator | Terminal default fg | The `│` character; inherits terminal default foreground | CONTEXT.md D-01 |
| Status bar | Terminal default fg/bg | Full-width text row at top | CONTEXT.md D-05 |
| Search input | `textinput.Model` bubbles v2 defaults | `/ search...` at bottom of diff pane | CONTEXT.md D-13 |

### 60/30/10 Mapping (adapted for TUI)

| Proportion | Surface | Color |
|------------|---------|-------|
| ~60% | Context lines, unchanged content, tree entries without status color, status bar | Terminal default (transparent) |
| ~30% | Added/removed/modified diff lines | ANSI 22 (dark green), 52 (dark red), 58 (dark amber) |
| ~10% | Selected tree row, search match highlights | Reverse video (`\x1b[7m`) |

Accent (reverse video) is reserved for: **selected tree row** and **search match highlights** — nothing else.

## Copywriting Contract

### Status Bar (D-05)

Format (always 1 row, padded to `termWidth` via `lipgloss.NewStyle().Width(termWidth).Render(...)`):

```
alturd — {filename} ({N} of {M} changed files)
```

- `{filename}` = `effectiveName(currentFile)` — `NewName` if set and not `/dev/null`, else `OldName`
- `{N}` = 1-based index of currently displayed file (`currentFile + 1`)
- `{M}` = total count of changed files (`len(files)`)
- When `searchMode = true`, append ` [SEARCH]` before padding

| Example | Condition |
|---------|-----------|
| `alturd — src/internal/diff/render.go (3 of 7 changed files)` | Normal mode |
| `alturd — src/internal/diff/render.go (3 of 7 changed files) [SEARCH]` | Search open |
| `alturd — old-file.go (1 of 1 changed files)` | Deleted file (OldName used) |

### Search Bar (D-13)

| Element | Value |
|---------|-------|
| Prompt character | `/` |
| Placeholder text | `search...` |

Set via `textinput.New()` with `ti.Prompt = "/"` and `ti.Placeholder = "search..."`.

### Empty State

The TUI is only launched when `len(files) > 0`. The "no changes" case is handled **before** `tea.NewProgram()` in `main.go`. No empty-state UI renders inside the TUI itself.

| Situation | Handling | Location |
|-----------|----------|----------|
| No changed files (`len(files) == 0`) | Print to stderr: `No changes found.` — exit 0 | `cmd/alturd/main.go` `run()`, before `tea.NewProgram()` |
| Full-repo tree toggle, `git ls-tree` returns empty | Not reachable in non-empty repos; tree shows no entries | `internal/tui/model.go` |

Copy for pre-TUI empty state: `No changes found.`

### Destructive Actions

| Action | Key | Confirmation Dialog | Exit Code |
|--------|-----|---------------------|-----------|
| Quit | `q` | None — immediate quit | 0 |
| Abort (difftool path) | `Q` | None — immediate abort | 1 |

No confirmation dialog for either action. Behavior matches the Python implementation.

## Key Binding Contract

Full key dispatch table for `Update()`. This is the authoritative reference for the executor implementing the key dispatch logic (CONTEXT.md D-17, D-18).

| Key | `searchMode` | Action | Requirement |
|-----|-------------|--------|-------------|
| `n` | `false` | Next hunk: `currentHunk++`; `diffVP.SetYOffset(hunkRows[currentHunk] - diffVP.Height()/2)` | NAV-01 |
| `N` | `false` | Previous hunk: `currentHunk--`; same centering formula | NAV-01 |
| `n` | `true` | Next search match: `diffVP.HighlightNext()` | SEARCH-01 |
| `N` | `true` | Previous search match: `diffVP.HighlightPrevious()` | SEARCH-01 |
| `]` | both | Next changed file: `currentFile = (currentFile + 1) % len(files)`; close search if open; call `refreshDiffContent()` | NAV-02, D-16 |
| `[` | both | Previous changed file: `currentFile = (currentFile - 1 + len(files)) % len(files)`; close search if open; call `refreshDiffContent()` | NAV-02, D-16 |
| `Tab` | `false` | Toggle focused pane: `treeFocused ↔ diffFocused`; swap `treeWidth` 24↔45; resize both viewports | NAV-03, TREE-02 |
| `v` | `false` | Toggle render mode: `FullFile ↔ HunkOnly`; call `refreshDiffContent()` | DIFF-06 |
| `/` | `false` | Open search: `searchMode = true`; shrink diff viewport by 1 row; `searchInput.Focus()` | SEARCH-01, D-13 |
| `Esc` | `true` | Close search: `searchMode = false`; clear query; `diffVP.SetHighlights(nil)`; restore diff viewport height | D-15 |
| `a` | `false` | Toggle all-files mode: `allFiles = !allFiles`; fetch `git ls-tree` if first toggle; rebuild tree | TREE-03, D-11 |
| `q` | `false` | Quit: `return m, tea.Quit()` | NAV-04, D-18 |
| `Q` | `false` | Abort: `os.Exit(1)` | NAV-04, D-18 |

Keys not listed are no-ops in their respective modes. In `searchMode = true`, all keys except `n`, `N`, `]`, `[`, `Esc`, and textinput character input are ignored.

### Hunk Centering Formula

```go
// In Update(), for 'n'/'N' hunk navigation:
targetOffset := m.hunkRows[m.currentHunk] - m.diffVP.Height()/2
if targetOffset < 0 {
    targetOffset = 0
}
m.diffVP.SetYOffset(targetOffset)
```

This centers the first changed line of the hunk vertically, showing surrounding context above and below (NAV-01). The 3-lines-of-context visual is achieved naturally when the hunk does not start near row 0.

| State Name | `searchMode` | `focusedPane` | `treeWidth` | Active Key Set |
|------------|-------------|---------------|-------------|----------------|

## Platform-Specific Rendering Contract

### Windows Resize Polling (D-08)

Bubbletea v2 does not deliver `tea.WindowSizeMsg` on Windows (VT input mode does not forward `WINDOW_BUFFER_SIZE_EVENT`). A platform-conditional polling tick is required.

| Property | Value |
|----------|-------|
| Polling interval | `time.Second / 4` (250 ms, 4 Hz) |
| Named constant | `windowsPollInterval = time.Second / 4` |
| Platform guard | `if runtime.GOOS == "windows"` — both in `Init()` and in the re-queue |
| Poll mechanism | `golang.org/x/term` `term.GetSize(int(os.Stdout.Fd()))` |

If polled size differs from `m.termWidth` or `m.termHeight`, treat as `tea.WindowSizeMsg` and call `handleResize(w, h)`.

### Windows Terminal Color Support

| Capability | Windows Terminal | Windows CMD | Mitigation |
|------------|-----------------|-------------|------------|
| 256-color (ANSI 48;5;N) | Yes | Partial | lipgloss v2 auto-downgrades via colorprofile |
| Alternate screen | Yes | Yes | `tea.WithAltScreen()` — normal usage |
| Reverse video (`\x1b[7m`) | Yes | Yes | No special handling needed |
