<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user search query → matcher | The typed query is untrusted text; it is used only as a needle for strings.Index over ANSI-stripped content, never interpolated into ANSI sequences, shell, or templates |
| git ls-tree paths → tree keys | (Plan 04 provides the paths) tree.go uses path strings only as display labels and map keys — never for filesystem access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-SEARCH | Tampering | findMatches search query | low | mitigate | Query is a plain needle for strings.Index over ansi.Strip'd text; it is never written back into ANSI/escape output, so a query containing escape bytes cannot inject terminal control sequences |
| T-03-PATH | Spoofing | tree path strings used as node keys | low | mitigate | tree.go treats paths as display strings and map keys only; no os.Open, os.Stat, or filepath join to disk happens here (V5 input validation, display-only) |
</threat_model>
