<objective>
Add the theme resolution layer that finally satisfies THEME-01's 50ms bound, and the
difftool single-file mode with its reduced-chrome title bar.

Purpose: Phase 3 left `main.go` calling `termenv.HasDarkBackground()` synchronously with no
external timeout, so THEME-01 is NOT already satisfied — 04-RESEARCH.md Pitfall A proves
`termenv.OSCTimeout` is a 5-second const that importing code cannot lower. This plan wraps
that call, adds the `--theme`/config override on top, and threads the difftool-mode flag
that decides whether the query is attempted at all (D-06). Difftool mode ships in the same
plan because D-06 makes theme resolution and difftool detection the same decision.

Output: `internal/config/theme.go` plus tests, `--theme` and `--difftool-*` flags with mode
dispatch in `cmd/alturd/main.go`, and difftool chrome in `internal/tui/model.go`.

This is an expansion plan — the phase's tracer slice (TOML file to live TUI dispatch) landed
in 04-01 Task 2 and is a precondition for every task here.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git (parent process) → alturd | `git difftool` invokes alturd as a subprocess, supplying `$LOCAL`/`$REMOTE`/`$MERGED` as argv values and `GIT_DIFF_PATH_COUNTER`/`GIT_DIFF_PATH_TOTAL` in the environment. |
| environment → terminal renderer | Env-var values would reach the user's terminal as rendered title-bar text if passed through unvalidated. |
| alturd → `git diff --no-index` subprocess | User-supplied file paths are passed to a git subprocess. |
| terminal → alturd | The OSC 11 response is a byte sequence read back from the terminal device. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-03-01 | Tampering | `GIT_DIFF_PATH_COUNTER` / `GIT_DIFF_PATH_TOTAL` rendered into the title bar | high | mitigate | Both values pass through `strconv.Atoi` and are re-rendered with `%d`; a non-numeric, empty or non-positive value collapses to the counter-less template. No raw env string ever reaches the terminal, so an escape sequence smuggled into either variable cannot be emitted (Task 2). |
| T-04-03-02 | Tampering | `exec.Command("git", "diff", "--no-index", ...)` with user-supplied paths | medium | mitigate | argv form only, never a shell string, with the `//nolint:gosec` + SECURITY comment convention copied from `internal/git/runner.go`; a `--` separator precedes the two path arguments so a path beginning with a hyphen cannot be parsed as a git option (Task 2). |
| T-04-03-03 | Tampering | Writes to `$LOCAL`, `$REMOTE` or `$MERGED` | high | mitigate | All three paths are opened read-only (`os.ReadFile` and git's own read of the temp files); no code path in this plan opens any of them for writing, truncation or removal. Encoded as prohibition P-04-03-02 (Tasks 2-3). |
| T-04-03-04 | Denial of Service | OSC 11 query hanging in a subprocess/tmux/SSH context | high | mitigate | D-06 skips the query outright in difftool mode, and the standalone path is bounded by the 50ms external race in `DetectDarkBackground`, so startup can never block on `termenv`'s 5-second internal const (Task 1, PITFALLS.md Pitfall 10, 04-RESEARCH.md Pitfall A). |
| T-04-03-05 | Information Disclosure | OSC 11 query bytes appearing in the user's scrollback when the terminal does not answer | medium | mitigate | Detection runs before `tea.NewProgram` takes the TTY and writes only the query to `os.Stdout`; on timeout no further output is produced by the detector.
